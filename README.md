# AV1 - Técnicas de Programação

**Requisitos: Node, npm e Typescript.** 

Antes de rodar pela primeira vez, instale os módulos:

```bash
> npm i
> npm install @types/node --save-dev

```

Para rodar:

```bash
> npm run dev
```



- Escolha entre os dados que deseja inserir (aeronaves, etapas, funcionarios, peças e testes), e após isso gere um relatório.

- Os arquivos serão criados e salvos em out/public/.

- JSON para os objetos e txt para o relatorio.
